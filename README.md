# График Плюс

Mac-приложение для расписания: строки из консоли сразу встают на график **месяц → неделя → день → время**.

## Сборка и запуск

Нужны Command Line Tools (уже достаточно) или Xcode:

```bash
./Scripts/build.sh
open "dist/График Плюс.app"
```

## Ввод

Одна строка — одно событие. Можно вставить сразу несколько.

```
октябрь / неделя 4 / вторник / 09:00 Урок немецкого #зелёный
21.10.2026 14:00-15:30 Совещание #синий
2026-10-21 18:00 Ужин
```

Команды в той же консоли: `удалить 21.10 14:00`, `цвет 21.10 14:00 розовый`, `очистить`, `помощь`.

Цвет выбирается чипами, системной палитрой или суффиксом `#синий` / `#5B8CFF`.

## Импорт и экспорт

- Импорт `.ics` или текстового файла в том же формате
- Экспорт `.ics` и «Открыть в Календаре macOS»
- Экспорт месяца в PDF
